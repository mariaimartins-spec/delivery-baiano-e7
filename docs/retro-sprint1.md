# Retrospectiva da Sprint 1
Equipe: E7   Data: 04/11/2026

## Começar
- Revisar os PRs no mesmo dia em que são abertos
- Avisar no grupo antes de abrir um PR
- Combinar no começo da aula quem faz qual parte, para ninguém ficar esperando o outro

## Parar
- Deixar o trabalho para o fim da aula e só subir para o GitHub no último minuto
- Commit com mensagem vaga ("mudanças") ou direto na main

## Continuar
- Cada uma trabalhando num arquivo ou seção, para evitar conflito no Git
- Revisar o PR uma da outra com comentário claro e respeitoso
- Fazer branch própria para cada tarefa

## Ações para a Sprint 2
1. O quê: avisar no grupo antes de abrir PR | Quem: todas | Como conferir: a Scrum Master da Sprint 2 olha no começo de cada aula
2. O quê: revisar o PR em até 1 aula depois de aberto | Quem: a revisora indicada no PR | Como conferir: nenhum PR fica aberto de uma aula para a outra
3. O quê: combinar as partes de cada integrante nos primeiros 10 minutos da aula | Quem: todas | Como conferir: cada issue tem responsável antes de começar a codar
