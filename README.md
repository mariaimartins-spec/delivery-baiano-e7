## Como contribuir
1. Atualize a main:
git switch main e git pull.
2. Crie uma branch:
git switch -c feat/nome-curto (ou fix/nome-curto).
3. Faça commits no formato tipo: descrição.
4. Envie a branch: git push -u origin feat/nome-curto.
5. Abra um pull request e peça a revisão de um colega.
6. Depois da aprovação, faça o merge e apague a branch.
